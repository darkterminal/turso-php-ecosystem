03 / CHOOSE A PATH

Pick the integration that fits your stack.

No one-size-fits-all runtime. Use native, HTTP, or Platform API depending on your environment and constraints.

A

Native extension

For local/libSQL performance and framework drivers that depend on the native extension.

  • Turso PHP Installer
  • Turso Client PHP
  • Turso Driver Laravel
  • Turso Doctrine DBAL
B

HTTP client

For environments where installing a native extension is not possible or not desirable.

  • Turso Client HTTP
  • Pure PHP + ext-curl
  • Works on shared hosting/CI
C

Platform API

For managing Turso Platform resources from PHP applications and automation scripts.

  • Turso API Client PHP
  • Turso Platform Laravel
  • Typed SDK, OpenAPI-pinned

04 / QUICK START

Start from the command line.

Install only what you need. The ecosystem is modular: packages can be used independently or combined in the same PHP stack.

ScopelibSQL/Turso PHP workflows
LicenseOpen source packages
CommunityDiscord, plain English
terminal
# Native extension installer
composer global require darkterminal/turso-php-installer
turso-php-installer install

# HTTP client (no extension)
composer require darkterminal/turso-client-http

# Platform API SDK
composer require darkterminal/turso-api-client-php

# Laravel / Doctrine integrations
composer require darkterminal/turso-platform-laravel
composer require tursodatabase/turso-driver-laravel
composer require tursodatabase/turso-doctrine-dbal
