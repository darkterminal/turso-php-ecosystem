Quick start

Start from the path you need.

Use the native installer for extension-based workflows, or pick a Composer package directly. Every card above links to the canonical repository/docs.

Scope note

This ecosystem focuses on PHP packages and integrations around libSQL/Turso workflows. For community support, use the Discord and keep discussions in plain English.

Terminal
# Native extension installer
composer global require darkterminal/turso-php-installer
turso-php-installer install

# HTTP client (no extension)
composer require darkterminal/turso-client-http

# Platform API SDK
composer require darkterminal/turso-api-client-php

# Laravel / Doctrine integrations
composer require darkterminal/turso-platform-laravel
composer require tursodatabase/turso-driver-laravel
composer require tursodatabase/turso-doctrine-dbal
